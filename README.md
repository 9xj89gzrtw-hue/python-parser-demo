# Парсер сайта на Python → CSV / Excel

Демонстрационный проект: обход каталога с пагинацией, разбор карточек и выгрузка
в CSV или XLSX. Целевой сайт — [quotes.toscrape.com](https://quotes.toscrape.com/),
публичная песочница, созданная специально для отработки скрапинга (свой сайт
заказчика подключается заменой двух функций).

## Что умеет

- обход пагинации с ограничением по числу страниц (`--pages`);
- пауза между запросами (`--delay`), вежливый User-Agent;
- проверка `robots.txt` перед обходом (`--ignore-robots` отключает);
- повторы с экспоненциальной паузой при сетевых ошибках и 5xx;
- выгрузка в CSV (UTF-8 BOM — Excel открывает без настройки кодировки) или XLSX;
- коды возврата 0/2 — удобно ставить в cron/планировщик;
- битые блоки не роняют обход: неполная карточка просто пропускается.

## Быстрый старт

```bash
pip3 install --user requests beautifulsoup4 openpyxl

python3 scrape_quotes.py --pages 3 --out quotes.csv
python3 scrape_quotes.py --pages 5 --out quotes.xlsx --delay 0.5
```

Пример вывода:

```
INFO страница 1: https://quotes.toscrape.com/
INFO   записей: 10
INFO страница 2: https://quotes.toscrape.com/page/2/
INFO   записей: 10
INFO готово: 20 строк(и) → quotes.csv
```

## Мониторинг цен (watch_books.py)

Второй сценарий того же проекта: регулярная проверка цен и отчёт об изменениях.

```bash
python3 watch_books.py --out snapshot.json --pages 2        # обновить снимок цен
python3 watch_books.py --out snapshot.json --notify         # + отчёт в Telegram
```

Отчёт различает четыре вида изменений: подешевело / подорожало (с процентом),
появился новый товар, пропал из каталога. Порог чувствительности — `--threshold`
(например, `1.0` — игнорировать колебания меньше 1%). Для Telegram нужны
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (или ключи `--telegram-token/--telegram-chat`).
Снимок хранится в JSON; запуск по расписанию — строка в cron (пример в docstring).

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты офлайн: разбирают локальную HTML-фикстуру, сеть не нужна.

## Под новый сайт

1. `extract_rows()` — CSS-селекторы карточек и полей;
2. `next_page_url()` — селектор ссылки «дальше» (или генерация URL по номеру страницы);
3. `FIELDS` / `Row` — состав колонок.

## Правовая заметка

Проект собирает только общедоступные страницы и уважает robots.txt. Перед
промышленным использованием на конкретном сайте нужно проверить его условия
использования и правила обработки данных.
